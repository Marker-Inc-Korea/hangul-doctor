# 🩺 hangul-doctor

> **코딩 에이전트의 한글·CJK 환경 문제 진단 도구** — 증상이 나기 전에 경고하고, 이미 망가진 흔적을 찾아내고, 원인을 알려줍니다.

![License](https://img.shields.io/badge/license-MIT-green)
![Dependencies](https://img.shields.io/badge/dependencies-none-lightgrey)
![Issues surveyed](https://img.shields.io/badge/surveyed%20issues-266-orange)

한글로 코딩 에이전트를 쓰다 보면 이런 일이 생깁니다. 한글을 치는데 자음·모음이 따로 놀고, 답변에 `���` 가 섞이고, 분명히 만든 한글 파일을 "없다"고 하고, 표가 자꾸 어긋납니다. 대부분은 **설정을 잘못한 게 아니라 이미 신고된 문제**입니다.

`anthropics/claude-code` 이슈를 조사한 결과 CJK 관련 신고가 **266건**, 그중 **67건이 미해결**이었습니다. 그런데 공식 터미널 설정 문서에는 CJK 항목이 아예 없고([#19118](https://github.com/anthropics/claude-code/issues/19118)), 우회법은 이슈 댓글에 흩어져 있습니다.

**hangul-doctor**는 그 흩어진 것을 한곳에 모아 **바로 확인할 수 있는 형태**로 만든 진단 도구입니다. 내 환경이 위험한지 미리 알려주고, 이미 망가진 흔적을 찾아주고, 겪은 증상의 원인을 짚어줍니다. 읽기만 하며 파일을 수정하지 않습니다.

---

## ⭐ 주요 특징

- **원인을 몰라 헤매는 시간을 없앱니다** — 알려진 문제 전체를 다룹니다. 클라이언트 내부에서 일어나는 것까지 포함해 왜 그런지와 어떻게 피하는지를 알려줍니다
- **경로 충돌을 계산합니다** — 한글 프로젝트 경로가 같은 저장소 폴더로 접히는지 실제 슬러그 규칙으로 판정합니다
- **증상으로 원인을 찾습니다** — "표가 어긋나요" 같은 한국어 증상을 넣으면 해당 이슈와 우회법을 돌려줍니다
- **의존성이 없습니다** — 표준 라이브러리만 씁니다. `uvx` 또는 `python -m` 으로 바로 실행

## 빠른 시작

```bash
uvx hangul-doctor check                  # 환경이 알려진 문제 조건에 걸리는지
uvx hangul-doctor scan                   # 작업 공간에서 망가진 흔적 찾기
uvx hangul-doctor why "표가 어긋나요"      # 증상으로 원인 찾기
uvx hangul-doctor issues                 # 알려진 문제 목록
```

설치 없이 쓰려면 저장소를 받아 `python -m hangul_doctor check` 로 실행합니다.

## ⭐ 대응 방식

증상마다 손댈 수 있는 지점이 다릅니다. 어떤 것은 미리 막을 수 있고, 어떤 것은 피해 갈 수 있으며, 어떤 것은 이미 벌어진 뒤에 찾아내야 합니다. 네 방식으로 나눠 대응합니다.

| 방식 | 하는 일 | 명령 |
|---|---|---|
| **예방** | 증상이 나타나기 전에 환경 조건을 경고 | `check` |
| **회피** | 못 고치는 문제를 피해 가는 방법 안내 | `check` · `why` |
| **감지** | 이미 망가진 흔적을 찾아 원인과 함께 제시 | `scan` |
| **수정** | 안전하게 고칠 수 있는 것만 (예정) | `fix` |

## 경로 충돌 판정

프로젝트별 상태는 `~/.claude/projects/<슬러그>` 에 저장됩니다. 관찰된 규칙은 **영숫자가 아닌 모든 문자를 `-` 로 치환**하는 것입니다. 한글은 한 글자가 `-` 하나가 되므로 **글자 수가 같은 한글 경로는 같은 슬러그**가 됩니다.

| 경로 | 슬러그 |
|---|---|
| `/home/u/프로젝트` | `-home-u-----` |
| `/home/u/데이터셋` | `-home-u-----` |
| `/home/u/문서모음` | `-home-u-----` |

세 프로젝트가 같은 폴더를 공유하므로 대화 기록과 프로젝트 기억이 섞입니다. 경고 없이 일어납니다.

```
$ hangul-doctor check

- 프로젝트 경로에 영문이 아닌 글자가 있습니다  #93743 #91735 #70076
   현재 경로가 저장소 폴더 이름으로 바뀔 때 '-home-u-----' 가 됩니다.
   글자 수가 같은 다른 한글 경로와 같은 폴더를 쓰게 되고,
   그러면 대화 기록과 기억이 조용히 섞입니다.
   → 프로젝트를 영문 경로에 두거나, 영문 경로에 두고 심볼릭 링크를 거세요
```

## 작업 공간 검사

```
$ hangul-doctor scan

! 깨진 글자(U+FFFD)가 남아 있는 파일 1개  #93848 #43746
   docs/broken.md:2  (2개)
   되돌릴 수 없습니다. 해당 부분을 다시 생성하도록 요청하세요.

! 한글이 이스케이프로 박힌 파일 1개  #83033
   src/config.json:1  (2개, 예: 한)
   모델이 한글을 그대로 쓰지 않고 코드로 바꿔 쓴 흔적입니다.

! 한글 파일명 저장 방식이 섞여 있습니다  #84966 #86829
   합친 방식 12개 / 풀어쓴 방식 3개
   에이전트가 '파일이 없다'고 할 수 있습니다.
```

검사 항목은 네 가지이며 전부 결정론적입니다.

| 항목 | 판정 기준 |
|---|---|
| 대체 문자 | 파일에 `U+FFFD` 포함 |
| 이스케이프 | `\uXXXX` 중 한글·가나·한자 코드포인트 대역만 (`A` 등은 무시) |
| 정규화 | 파일명이 NFC·NFD로 혼재 |
| 레거시 인코딩 | UTF-8 디코딩 실패 + CP949·EUC-KR로 한글 복원 성공 |

## ⚠️ 한계

- **수정이 아니라 진단이 목적입니다.** 렌더링·붙여넣기·입력기처럼 클라이언트 내부에서 일어나는 동작은 이 도구의 수정 범위 밖입니다. 해당 항목은 원인과 회피법을 제시하며, 수정까지 가능한 항목은 위 표에 `수정`으로 표시했습니다
- 문제 목록은 **신고 내용을 정리한 것**이며, 항목별 재현 확인은 진행 중입니다
- 슬러그 규칙은 실제 `~/.claude/projects` 를 관찰해 역산한 것입니다. 공식 명세가 아니므로 버전에 따라 달라질 수 있습니다
